# skills

General-purpose guidance and navigation for the hypermemetic-ai organization.

This repo is not the methodology (that's [`ought`](https://github.com/hypermemetic-ai/ought)). It's the place for things that don't fit a dedicated repo yet — currently Kimi Code skills guidance, and potentially broader org navigation later.

## Conventions

- Keep content here methodology-agnostic.
- If something clearly belongs in `ought` (methodology, ADRs, recipes), move it there.
- If something belongs to a specific project, keep it in that project's repo.
- Skill-format docs should link to Kimi's official documentation rather than duplicating it.
